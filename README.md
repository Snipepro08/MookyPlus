# 🚀 MookyPlus — Extension Chrome pour Mooky.live

**MookyPlus** est une extension Google Chrome conçue pour personnaliser et améliorer l'interface du réseau social **[Mooky.live](https://mooky.live)**.

---

## ✨ Fonctionnalités actuelles

- 🔘 **Bouton MookyPlus rapide** : Ajout d'un bouton d'accès rapide avec le logo officiel directement dans la barre supérieure du site.
- 🎨 **Personnalisation de l'interface** : Améliorations visuelles et pré-configuration pour des thèmes personnalisés.
- 💣 **Invite de commande** : pour le fun mais aussi pour faire des actions utilitaires

---

## 📥 Comment installer l'extension (Gratuit & Rapide)

Comme l'extension n'est pas encore publiée sur le Chrome Web Store, tu peux l'installer très facilement en **Mode Développeur** en suivant ces étapes :

### Étape 1 : Télécharger l'extension
1. Clique sur le bouton vert **`Code`** en haut à droite de cette page GitHub.
2. Clique sur **`Download ZIP`**.
3. Extrais le fichier `.zip` téléchargé dans un dossier sur ton ordinateur (par exemple dans tes *Documents* ou sur ton *Bureau*).

---

### Étape 2 : Activer le mode Développeur sur Chrome
1. Ouvre **Google Chrome** (ou n'importe quel navigateur basé sur Chromium comme Brave, Edge ou Opera).
2. Dans la barre d'adresse, tape : `chrome://extensions/` et appuie sur **Entrée**.
3. En haut à droite de la page, **active l'interrupteur "Mode développeur"**.

---

### Étape 3 : Charger l'extension
1. Clique sur le bouton **`Charger l'extension non empaquetée`** *(Load unpacked)* en haut à gauche.
2. Sélectionne le dossier où tu as extrait le projet (le dossier qui contient le fichier `manifest.json`).
3. **C'est prêt !** Rendez-vous sur **[Mooky.live](https://mooky.live)** pour profiter des nouvelles fonctionnalités ! 🎉

---

## 🔄 Comment mettre à jour l'extension ?

1. Télécharge la dernière version du code depuis ce dépôt GitHub.
2. Remplace les anciens fichiers par les nouveaux dans ton dossier.
3. Va sur `chrome://extensions/` et clique sur l'icône **Rafraîchir 🔄** sur la carte de l'extension **MookyPlus**.
